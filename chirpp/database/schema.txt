Database: PostgreSQL

Table: patients Description: Demographic data about patients Columns:
mrn: Integer, Primary Key, unique patient identifier
dob: Date

Table: visits Description: Information about each patient visit Columns:
csn: Integer, Primary Key, unique visit identifier
sex: String, patient’s biological sex (e.g., M, F)
age: Integer
mrn: Integer, Foreign Key (patients.mrn)
arrival_date: Date
arrival_time: Time
day_of_week: String
sk_narrative: Text
phac_narrative: Text
postal_code: String
chief_complaint: String
diagnosis: String
disposition: String, patient disposition
ctas: Integer, nullable, triage level
los: Float, length of stay in hours
processed: Boolean, whether this visit has been processed
address: String
city: String
province: String
probs: Float, probability of referral to chirpp_report
sk_narrative_vector: TSVector, Computed (to_tsvector('english', sk_narrative)), full-text search vector for sk_narrative
phac_narrative_vector: TSVector, Computed (to_tsvector('english', phac_narrative)), full-text search vector for phac_narrative

Table: referrals Description: Referrals of a patient to different units Columns:
id: Integer, Primary Key
csn: Integer, Foreign Key (visits.csn)
referrals: String

Table: problems Description: Problems described by the patient or identified by the doctor Columns:
id: Integer, Primary Key
csn: Integer, Foreign Key (visits.csn)
problem: String

Table: notes Description: Clinical notes for each patient and visit Columns:
id: Integer, Primary Key
csn: Integer, Foreign Key (visits.csn)
note_type: String
author_type: String
author_service: String
note_text: Text
notes_ts_vector: TSVector, Computed (to_tsvector('english', note_text)), full-text search vector for note_text
